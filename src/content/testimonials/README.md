Client quotes go here, one YAML file each (only add quotes the client has approved):

```yaml
quote: What the client said, in their words.
name: Client's name
title: Their role
company: Their business
project: hayesx-pilot-app # optional: id of the related project in src/content/projects/
order: 1
```

The testimonials sections on the homepage and case studies stay hidden until a file exists.
